# Phase 3: Authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate the app behind credential login — DIY `jose` JWT sessions in an httpOnly cookie, a `proxy.ts` optimistic redirect, and a DAL `verifySession()` that every protected read/action re-checks — so `demo@example.com` / `demo1234` can log in, land on a protected page, and log out.

**Architecture:** Server-first App Router. Pure JWT helpers (`jose`) live in `src/lib/jwt.ts` (unit-tested); cookie management in `src/lib/session.ts` (`server-only`, async `cookies()`); session verification in `src/lib/dal/auth.ts` (memoized with React `cache()`). Login/logout are Server Actions validated by a shared Zod schema. `src/proxy.ts` does optimistic cookie-only redirects; the real security boundary is `verifySession()` inside actions/reads.

**Tech Stack:** Next.js 16 (App Router), React 19, `jose`, Zod 4, `bcryptjs` (already present), `server-only`, Jest + RTL.

**Spec:** `docs/superpowers/specs/2026-07-02-phase-3-auth-design.md` (and parent `2026-06-13-jira-kanban-design.md` §5–§9).

## Global Constraints

_(Every task's requirements implicitly include this section.)_

- **This Next.js has breaking changes — trust the bundled docs in `node_modules/next/dist/docs`, not prior Next knowledge.**
- Route protection uses **`src/proxy.ts`**, NOT `middleware.ts` (renamed/deprecated in Next 16). Default-export `async function proxy(req: NextRequest)`; Node runtime; `config.matcher` excludes `api`, `_next/static`, `_next/image`, `favicon.ico`.
- Proxy does **optimistic (cookie-only) checks**; it is NOT the security boundary. Every Server Action and protected read calls `verifySession()` first.
- `cookies()` (from `next/headers`) is **async** — always `await cookies()`. Cookies may be `set`/`delete`d only inside a Server Action (not during render).
- `redirect()` from `next/navigation` **throws** — call it OUTSIDE any `try/catch`.
- Directives: Server Action files start with `'use server'`; client components start with `'use client'` (before imports).
- Session: signed JWT (HS256, `jose`) in an httpOnly cookie named **`session`**; payload is minimal (`{ userId, expiresAt }`); 7-day expiry; cookie opts `httpOnly: true, sameSite: 'lax', path: '/', secure: process.env.NODE_ENV === 'production'`. Secret from `process.env.SESSION_SECRET`. **Never commit `.env`.**
- Zod **v4** syntax: `z.email({ error: '…' })`, `z.string().min(1, { error: '…' })`, `parsed.error.flatten().fieldErrors`.
- **All Prisma access stays in `src/lib/dal/`.** Files under `src/lib/` use **relative imports** (`../prisma`, `./jwt`) to match existing DAL files; code under `src/app/`, `src/actions/`, `src/schemas/` uses the **`@/`** alias.
- Registration is out of scope; users come only from the seed. Wrong credentials return a single generic error (no user-enumeration).
- Demo login: `demo@example.com` / `demo1234`.

- [ ] **Step 3: Implement the pure JWT helpers** — `src/lib/jwt.ts`

```ts
import { SignJWT, jwtVerify } from 'jose'

export const SESSION_COOKIE_NAME = 'session'

const encodedKey = new TextEncoder().encode(process.env.SESSION_SECRET)

export type SessionPayload = {
  userId: string
  expiresAt: string
}

export async function encrypt(payload: SessionPayload): Promise<string> {
  return new SignJWT(payload)
    .setProtectedHeader({ alg: 'HS256' })
    .setIssuedAt()
    .setExpirationTime('7d')
    .sign(encodedKey)
}

export async function decrypt(
  token: string | undefined,
): Promise<SessionPayload | null> {
  if (!token) return null
  try {
    const { payload } = await jwtVerify(token, encodedKey, {
      algorithms: ['HS256'],
    })
    if (typeof payload.userId !== 'string') return null
    return {
      userId: payload.userId,
      expiresAt: typeof payload.expiresAt === 'string' ? payload.expiresAt : '',
    }
  } catch {
    return null
  }
}
```

- [ ] **Step 5: Implement cookie management** — `src/lib/session.ts`

```ts
import 'server-only'
import { cookies } from 'next/headers'
import {
  decrypt,
  encrypt,
  SESSION_COOKIE_NAME,
  type SessionPayload,
} from './jwt'

const SESSION_DURATION_MS = 7 * 24 * 60 * 60 * 1000

export async function createSession(userId: string): Promise<void> {
  const expiresAt = new Date(Date.now() + SESSION_DURATION_MS)
  const token = await encrypt({ userId, expiresAt: expiresAt.toISOString() })
  const cookieStore = await cookies()
  cookieStore.set(SESSION_COOKIE_NAME, token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    expires: expiresAt,
    sameSite: 'lax',
    path: '/',
  })
}

export async function deleteSession(): Promise<void> {
  const cookieStore = await cookies()
  cookieStore.delete(SESSION_COOKIE_NAME)
}

export async function getSessionPayload(): Promise<SessionPayload | null> {
  const cookieStore = await cookies()
  const token = cookieStore.get(SESSION_COOKIE_NAME)?.value
  return decrypt(token)
}
```

### Task 4: Auth DAL — session verification

Centralized authorization: `verifySession()` (redirects if no valid session) and `getCurrentUser()` (safe fields only). Both memoized with React `cache()` so repeated calls in one render hit the DB/cookie once. Lives in `dal/` with relative imports.

**Files:**
- Create: `src/lib/dal/auth.ts`

**Interfaces:**
- Consumes: `getSessionPayload` (`../session`), `prisma` (`../prisma`).
- Produces: `verifySession(): Promise<{ userId: string }>` (redirects to `/login` if unauthenticated), `getCurrentUser(): Promise<{ id, name, email, avatarColor } | null>`.

- [ ] **Step 1: Implement** — `src/lib/dal/auth.ts`

```ts
import { cache } from 'react'
import { redirect } from 'next/navigation'
import { getSessionPayload } from '../session'
import { prisma } from '../prisma'

export const verifySession = cache(async () => {
  const session = await getSessionPayload()
  if (!session?.userId) {
    redirect('/login')
  }
  return { userId: session.userId }
})

export const getCurrentUser = cache(async () => {
  const { userId } = await verifySession()
  return prisma.user.findUnique({
    where: { id: userId },
    select: { id: true, name: true, email: true, avatarColor: true },
  })
})
```

### Task 5: Auth Server Actions — login and logout

`login` validates, checks credentials, creates the session, and redirects; `logout` clears the session. Typed results for `useActionState`; `redirect()` called outside try/catch.

**Files:**
- Create: `src/actions/auth.ts`

**Interfaces:**
- Consumes: `loginSchema` (`@/schemas/auth`), `getUserByEmail` (`@/lib/dal/users`), `createSession`/`deleteSession` (`@/lib/session`), `bcryptjs`.
- Produces: `type LoginState = { error?: string; fieldErrors?: { email?: string[]; password?: string[] } } | undefined`, `login(prevState: LoginState, formData: FormData): Promise<LoginState>`, `logout(): Promise<void>`.

- [ ] **Step 1: Implement** — `src/actions/auth.ts`

```ts
'use server'

import { redirect } from 'next/navigation'
import bcrypt from 'bcryptjs'
import { loginSchema } from '@/schemas/auth'
import { getUserByEmail } from '@/lib/dal/users'
import { createSession, deleteSession } from '@/lib/session'

export type LoginState =
  | {
      error?: string
      fieldErrors?: { email?: string[]; password?: string[] }
    }
  | undefined

export async function login(
  _prevState: LoginState,
  formData: FormData,
): Promise<LoginState> {
  const parsed = loginSchema.safeParse({
    email: formData.get('email'),
    password: formData.get('password'),
  })

  if (!parsed.success) {
    return { fieldErrors: parsed.error.flatten().fieldErrors }
  }

  const user = await getUserByEmail(parsed.data.email)
  if (!user || !bcrypt.compareSync(parsed.data.password, user.passwordHash)) {
    return { error: 'Invalid email or password.' }
  }

  await createSession(user.id)
  redirect('/boards')
}

export async function logout(): Promise<void> {
  await deleteSession()
  redirect('/login')
}
```

### Task 8: Route protection with proxy.ts

Optimistic redirects at the edge of every request: unauthenticated visitors to any non-`/login` route go to `/login`; authenticated visitors to `/login` go to `/boards`. Cookie-only — no DB.

**Files:**
- Create: `src/proxy.ts`

**Interfaces:**
- Consumes: `decrypt`, `SESSION_COOKIE_NAME` (`@/lib/jwt`), `NextRequest`/`NextResponse` (`next/server`).

- [ ] **Step 1: Implement** — `src/proxy.ts`

```ts
import { NextRequest, NextResponse } from 'next/server'
import { decrypt, SESSION_COOKIE_NAME } from '@/lib/jwt'

export default async function proxy(req: NextRequest) {
  const path = req.nextUrl.pathname
  const isLoginRoute = path === '/login'

  const token = req.cookies.get(SESSION_COOKIE_NAME)?.value
  const session = await decrypt(token)

  // Optimistic checks only — the real auth boundary is verifySession() in the DAL.
  if (!session?.userId && !isLoginRoute) {
    return NextResponse.redirect(new URL('/login', req.nextUrl))
  }

  if (session?.userId && isLoginRoute) {
    return NextResponse.redirect(new URL('/boards', req.nextUrl))
  }

  return NextResponse.next()
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
}
```
